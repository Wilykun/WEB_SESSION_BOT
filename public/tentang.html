Tentang SessionBot

SessionBot adalah web pairing untuk bot WhatsApp berbasis Baileys latest mengikuti pola resmi V1 dari ReadSwEsm_V1: browser Ubuntu + Chrome, pairing code V1 (requestPairingCode, custom 8 karakter, berlaku 3 menit), dan sesi satu file hisoka.json.

  • Validasi realtime — nomor, negara, dan operator dicek langsung dari server, bukan ditebak.
  • Dua metode — Pairing Code (custom / acak) dan QR Code yang berganti berkala.
  • Sesi satu file — sessions/<nomor>/hisoka.json beserta backup .good / .bak.
  • Otomatis ke owner — setelah file maksimal, sesi dikirim sebagai dokumen ke owner dan sesi web terputus sendiri.
