Tutorial Singkat
  1. Masukkan nomor WhatsApp — sistem mengecek valid, negara, dan operator secara realtime.
  2. Pilih metode — Pairing Code (ketik 8 karakter di WhatsApp) atau QR Code (pindai kamera).
  3. Kode custom? Aktifkan “Kode Custom”, ketik 1–8 karakter A–Z 0–9. Kekurangan diisi ‘0’ di belakang, contoh WILY → WILY-0000. Kosongkan untuk kode acak dari WhatsApp.
  4. Tersambung — bot terhubung, tunggu file hisoka.json maksimal.
  5. Sesi terkirim — file sesi dikirim otomatis ke owner, lalu sesi web terputus sendiri. File tetap tersimpan di server.

Kode pairing berlaku 3 menit. QR berganti berkala dari WhatsApp. Jangan pernah bagikan file hisoka.json ke siapa pun — isinya kredensial WhatsApp kamu.

Tentang SessionBot

SessionBot adalah web pairing untuk bot WhatsApp berbasis Baileys latest mengikuti pola resmi V1 dari ReadSwEsm_V1: browser Ubuntu + Chrome, pairing code V1 (requestPairingCode, custom 8 karakter, berlaku 3 menit), dan sesi satu file hisoka.json.

  • ✓Validasi realtime — nomor, negara, dan operator dicek langsung dari server, bukan ditebak.
  • ✓Dua metode — Pairing Code (custom / acak) dan QR Code yang berganti berkala.
  • ✓Sesi satu file — sessions/<nomor>/hisoka.json beserta backup .good / .bak.
  • ✓Otomatis ke owner — setelah file maksimal, sesi dikirim sebagai dokumen ke owner dan sesi web terputus sendiri.
