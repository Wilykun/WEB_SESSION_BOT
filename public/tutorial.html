Cara Pairing Bot WhatsApp

Lima langkah saja: nomor → metode → kode/QR → tersambung → sesi terkirim ke owner.

1

Masukkan Nomor

Ketik nomor WhatsApp kamu di kolom nomor. Sistem mengecek valid, negara, dan operator secara realtime dari server. Format otomatis: 08… → 62…, +62… → 62…. Nomor luar negeri (+1, +44) tetap didukung.

2

Pilih Metode

Kalau nomor valid, muncul dua kartu: Pairing Code — ketik 8 karakter di WhatsApp, atau QR Code — pindai dengan kamera WhatsApp. Pilih salah satu, lalu tekan Minta Kode / Minta QR.

3

Kode / QR

Pairing Code: kode 8 karakter tampil per kotak, berlaku 3 menit. Buka WhatsApp → Perangkat Tertaut → Tautkan dengan Nomor Telepon, lalu ketik kodenya. QR: pindai dengan Perangkat Tertaut. QR diterbitkan WhatsApp dan berganti berkala (±20–60 detik).

4

Tersambung

Kalau berhasil, muncul “Kamu Tersambung”. Bot terhubung — sekarang tunggu file hisoka.json jadi maksimal: terdaftar, ada akun, pre-key cukup, dan ukuran stabil.

5

Sesi Terkirim

File hisoka.json dikirim otomatis sebagai dokumen ke owner 6289688206739. Setelah terkirim, sesi web terputus sendiri — file tetap tersimpan aman di server (sessions/<nomor>/hisoka.json).

Kode Custom — Bikin Kodemu Sendiri

Pilih Kode Custom, lalu ketik 1–8 karakter A–Z 0–9. Kekurangan karakter diisi ‘0’ di belakang secara otomatis:

  • WILY → WILY-0000
  • BOT123 → BOT1-2300
  • ABCDEFGH → ABCD-EFGH

Kosongkan atau pilih Kode Acak kalau mau WhatsApp yang menentukan kodenya.

Setelah Tersambung, Apa yang Terlihat?

Panel hasil menampilkan pipeline 5 langkah, terminal log realtime, dan tabel info sesi — nomor bot, file sesi, ukuran, jumlah pre-key / session / identity-key. Yang tampil hanya angka dan status, isi kunci tidak pernah ditampilkan.

Kalau pengiriman ke owner gagal, tekan tombol Kirim ke Owner untuk mengirim ulang. Tombol Putuskan Sesi memutuskan bot dari web ini.

Keamanan — Penting!

File hisoka.json berisi kredensial WhatsApp bot kamu. Jangan pernah bagikan ke siapa pun, jangan kirim ke grup, jangan unggah ke internet. File hanya dikirim ke nomor owner yang sudah ditentukan, dan tetap tersimpan di server.

Kode pairing hanya berlaku 3 menit. Kalau kedaluwarsa, minta kode baru — kode lama tidak bisa dipakai lagi.
